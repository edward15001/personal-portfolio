EDUARDO.OS — IDENTIDAD VISUAL

De brutalista a Platinum

El portfolio empezó como una web brutalista con scroll infinito, y pasó por un concepto de "escritorio retro" estilo Windows 9x antes de convertirse en esto: un escritorio inspirado en Mac OS 9.2, con su paleta Platinum y su lenguaje de ventanas.

PALETA

Grises Platinum (#DCDEE1 / #EFF0F2) para el chrome del sistema, azul de selección (#3B78D8) para acciones y foco, y verde terminal (#39FF88) reservado solo para la Terminal — el resto del sistema se mantiene neutro para no competir con el contenido de cada proyecto.

TIPOGRAFÍA

Fuente de sistema (-apple-system, Segoe UI, Helvetica) para todo el chrome, igual que hacía el propio Mac OS 9 con sus tipos de sistema. IBM Plex Mono queda reservado exclusivamente para la Terminal.

ICONOGRAFÍA

Iconos reales extraídos de packs de sistema de Mac OS 9 y Windows 98, probados uno junto a otro hasta decidir cuál encajaba mejor con cada elemento — documento, carpeta, terminal y correo entre ellos (mira la ventana "Recursos" en el menú Archivo).

FONDO Y EFECTO CRT

El wallpaper se procesa como tres capas de color (rojo/verde/azul) ligeramente desalineadas y mezcladas en modo screen, más un barrido de scanlines — la aberración cromática y el parpadeo de un monitor de tubo viejo.

IDENTIDAD POR PROYECTO

Dentro de PROYECTOS.EXE cada proyecto conserva su propia identidad — tomada de cómo está construido de verdad, no elegida a mano: verde neón para SafeGram, papel cálido con acento savia para NutroVia, cristal negro con duotono naranja/azul para el Angular Task Manager, negro con el azul y el rojo que salen del propio algoritmo para el generador de Mandelbrot, y el verde chartreuse neón de Theme.java para Buscaminas — mientras el chrome de la ventana se mantiene siempre Platinum.

EDUARDO.OS — PROCESO CREATIVO Y DE DESARROLLO

Construido a base de iteración

Este escritorio no salió así a la primera. Empezó como un concepto HTML estático con tres proyectos de relleno, y se fue reescribiendo por completo en varias pasadas, cada una a partir de feedback directo sobre lo que ya estaba construido.

DEL CONCEPTO A LOS 5 PROYECTOS REALES

Se sustituyeron los proyectos placeholder por los cinco reales — SafeGram, NutroVia, Angular Task Manager, el generador de Mandelbrot y Buscaminas — con sus imágenes, stack y enlaces reales a GitHub y a las demos en producción.

EL GESTOR DE VENTANAS

Escrito desde cero con Pointer Events: arrastre, redimensionado desde la esquina, zoom a pantalla completa y un minimizado con animación "genie" que encoge la ventana hasta su icono en la barra inferior — y la restaura con la animación inversa al volver a hacer clic.

SELECCIÓN Y PAPELERA

Arrastrar sobre el escritorio abre una selección tipo marquee sobre los iconos, igual que en cualquier escritorio de verdad; arrastrar la selección hasta la papelera cierra las apps seleccionadas que estén abiertas.

UN PIVOTE A MITAD DE CAMINO

La primera pasada del escritorio tenía una estética más Windows 9x. A mitad de proceso se decidió pivotar por completo a Mac OS 9.2 — barra de menú Apple arriba, ventanas Platinum, los tres botones clásicos — y de ahí salió la versión actual.

TERMINAL Y CONTACTO REALES

La Terminal responde a comandos reales (help, projects, open <proyecto>...) y el formulario de CONTACTO.EXE envía los mensajes de verdad a través de Web3Forms, sin backend propio.

IDENTIDAD VISUAL PARA CADA PROYECTO

Los tres proyectos que quedaban con texto "PENDIENTE" —Angular Task Manager, el generador de Mandelbrot y Buscaminas— se resolvieron entrando en su código fuente real: la paleta naranja/azul y el cristal de Angular salen de su propio styles.css, el negro/azul/ rojo de Mandelbrot sale directamente de la función que colorea cada píxel, y el verde chartreuse de Buscaminas sale de su Theme.java. Nada de esto se inventó a mano — se documentó lo que cada proyecto ya era.
